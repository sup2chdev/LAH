# LAH — Local Agent Harness

Отдельное Windows-приложение на основе DeepSeek Harness. Текущая версия — `0.0.1-prealpha`: локальный чат, выбор рабочей папки, история сеансов и четыре инструмента чтения и поиска. Приложение не требует аккаунта, API-ключа или кредитов. Модель не входит в сборку и не обучается.

Готовая portable-сборка после `pnpm package:lah`: `apps/lah/release/LAH-win32-x64/LAH.exe`. Запускайте exe вместе со всей папкой сборки. Выберите рабочую папку, откройте настройки и задайте URL работающего локального OpenAI-совместимого сервера, например `http://127.0.0.1:1234/v1`. Найдите или введите ID модели. Укажите реальный размер её контекста. Доступны HTTP(S) endpoints на loopback: localhost, 127.0.0.1 и ::1. Подключение реальной модели ещё требует отдельной проверки.

В приложении нет авторизации DeepSeek, биллинга, облачного поиска, телеметрии или автоматического обновления. Инструменты `list_directory`, `search_files`, `search_content`, `read_file` работают внутри выбранной папки, проверяют аргументы и возвращают ограниченные результаты. Записи файлов, терминала и сетевых инструментов в меню нет. Подробности и пределы первой версии: [приложение](apps/lah/README.md), [локальный runtime](apps/lah/runtime/README.md).

SubLLM пока не подключён. Следующий этап — поиск и рекомендация нескольких инструментов через SubLLM; аргументы формирует основная локальная LLM. Обучение ранжировщика и обучение генерации аргументов остаются отдельными задачами.

Исходная основа сохраняет лицензию MIT и уведомления об авторах в [LICENSE](LICENSE). Upstream-код остаётся в репозитории для дальнейшей поддержки форка; приложение собирает только выбранные агентные модули и собственный интерфейс LAH. Оригинальный README описывает upstream-продукт, а этот файл — LAH.

## Сборка из исходников

Нужны Node.js 24 и pnpm. Команды выполняются в корне этого репозитория:

```powershell
pnpm install --filter @lah/desktop... --ignore-scripts --frozen-lockfile
$env:electron_config_cache = "$PWD\.cache\electron"
node apps/lah/node_modules/electron/install.js
pnpm build:lah
pnpm test:lah
pnpm start:lah
pnpm package:lah
```

Portable-сборка является неподписанной сборкой разработки. Пользовательские настройки и история находятся в `%APPDATA%\LocalAgentHarness`. LAH не меняет данные официального DeepSeek Harness.
